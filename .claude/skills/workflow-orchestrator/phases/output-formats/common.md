# 通用输出格式规范

> **加载时机**: 编排器在需要展示格式化输出时加载本文件（阶段预览、总结确认、澄清展示等）。
> **适用范围**: 所有阶段通用。

---

## 1. 阶段预览格式

```
** 📋 阶段预览: [阶段名称] **

📌 需求: [需求名称]
🔄 当前阶段: [阶段 ID] ([N/15])
🤖 调用 Agent: [Agent 名称]

📥 输入:
  - [前序阶段产物列表]

📤 预期输出:
  - [本阶段产出物列表]

⚠️  已知风险: [N] 项

请确认是否执行？[执行 / 取消]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 2. 阶段总结格式

```
** ✅ 阶段完成: [阶段名称] **


📄 产出物:
  - [产物文件路径及简述]

🔑 关键决策:
  - [本阶段的关键决策点]

⚠️  新增风险: [N] 项
📊 总体风险: [N] 项

下一阶段: [下一阶段名称]
请选择: [确认进入下一阶段 / 回退到上一阶段]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 3. 澄清展示格式

```
** ❓ 待澄清问题: [阶段名称] **

📊 共 [N] 个待确认问题（Agent 已提供建议答案，您可快速采纳或修改）

🔴 阻塞性问题 (必须回答):
  Q1. [问题内容]
      背景: [上下文说明]
      💡 建议答案: [Agent 的推断答案]
      → 请选择: [采纳] [修改] [跳过]

🟡 重要问题:
  Q2. [问题内容]
      背景: [上下文说明]
      💡 建议答案: [Agent 的推断答案]
      → 请选择: [采纳] [修改] [跳过]

🟢 建议性问题 (可跳过):
  Q3. [问题内容]
      背景: [上下文说明]
      💡 建议答案: [Agent 的推断答案]
      → 请选择: [采纳] [修改] [跳过]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💬 操作说明:
  - "采纳": 直接采用 Agent 的建议答案
  - "修改": 输入您的答案替代建议答案
  - "跳过": 跳过该问题（将记录为风险）
  - "全部采纳": 一键采纳所有问题的建议答案（快速通道）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 5. PRD 重复检测提示格式

```
** ⚠️ 检测到该 PRD 已存在关联的工作流 **

📄 PRD 文档: [PRD 路径]
📂 已关联需求: [需求名称]
🆔 需求 ID: [需求 ID]
🔄 当前阶段: [currentPhase] ([N]/15)
🕐 最后更新: [updatedAt]
📊 已识别风险: [N] 项

请选择操作:
  1️⃣ 继续该需求 → 从当前断点恢复执行
  2️⃣ 重新开始 → 删除旧需求，创建新工作流（⚠️ 将删除所有已有产物）
  3️⃣ 取消操作 → 返回工作流列表

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
