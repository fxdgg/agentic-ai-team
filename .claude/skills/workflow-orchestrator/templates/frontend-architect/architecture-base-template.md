---

## 使用说明

本模板定义了前端架构文档的通用骨架结构。每个平台的架构文档都必须包含以下基础章节。平台专属内容通过加载对应的平台模板进行扩展。

## 输出规则

1. **front-matter 必须填写**: qualityGate、qualityScore、qualityTimestamp、platform、risks（可为空数组）
2. **接口引用格式**: 所有接口定义必须以 `引用总纲 API-xxx` 开头
3. **改动清单必须关联需求点**: 每个改动必须标注对应的用户故事编号
4. **任务拆解必须可执行**: Task 列表必须足够详细，让下游开发 Agent 无需回溯架构文档
