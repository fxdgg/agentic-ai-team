## 3. API 设计

> ⚠️ **协作约束**: 本节接口设计**必须引用**总纲 `tech-requirements.md` §3.2 中定义的接口基准契约。
> - ✅ **允许**: 细化参数校验规则、错误码、请求/响应示例、Swagger 注解

## API 设计检查清单

- [ ] **引用检查**: 所有接口均已标注总纲引用（API-xxx）
- [ ] **签名一致性**: API Path、字段名、字段类型与总纲完全一致
- [ ] 遵循 RESTful 设计规范
- [ ] 请求/响应结构使用统一包装 Result<T>
- [ ] 分页接口使用 PageQuery/PageResult
- [ ] 参数校验注解已添加（@NotBlank / @Size / @Pattern 等）
- [ ] 错误码已定义
- [ ] 接口文档（Swagger）已补充
