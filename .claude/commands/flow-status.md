# 查看工作流状态

## 指令概述

本指令用于快速查看当前项目中所有工作流的状态概览，包括进度、当前阶段、风险等信息。

**核心原则：只读查看，不修改任何状态文件。**

---

## 执行流程

### Step 1：扫描工作流目录

1. 列出 `docs/workflows/` 目录下的所有子目录（每个子目录代表一个需求工作流）
2. 排除 `evolve-log/` 目录（进化日志，非需求工作流）

### Step 2：读取各需求状态

对每个需求目录：

1. 读取 `state.json`，提取以下信息：
   - `id` — 需求 ID
   - `name` — 需求名称
   - `currentPhase` — 当前阶段
   - `phaseHistory` — 阶段历史（计算进度百分比）
   - `platforms` — 各平台状态
   - `updatedAt` — 最后更新时间
   - Parallel Agent 状态（`analyseTechMode`、`architectBackendMode`、`implementMode`、`buildVerifyMode`）
   - `architectBackendCheckpoint` — 检查点信息（如有）

2. 读取 `risks.json`（如果存在），统计 open 风险数量

### Step 4：提示可用操作

```
可用操作：
  → /flow-run          — 启动新工作流或继续已有工作流
  → /flow-status       — 刷新状态（当前指令）
  → /evolve            — 提交流水线改进建议
  → /evolve-apply      — 审阅并落地改进建议
```


### docs/workflows/ 目录不存在时

提示用户尚未初始化工作流系统，可通过 `/flow-run` 启动第一个工作流。

## 行为约束

1. **只读操作**：不修改任何文件
2. **快速展示**：不启动工作流编排器 Skill
3. **容错处理**：`state.json` 读取失败的需求标记为"状态异常"而非报错退出
