# BUILD_VERIFY 阶段 Agent Teams 输出格式

> **加载时机**: 仅在 BUILD_VERIFY 阶段的预览/进度监控/总结确认时加载。
> **前置依赖**: 需同时加载 `output-formats/common.md`。

---

## 10. BUILD_VERIFY 阶段 Agent Teams 预览格式

```
** 📋 阶段预览: BUILD_VERIFY（Agent Teams 模式） **

📌 需求: [需求名称]
🔄 当前阶段: BUILD_VERIFY (10/15)
🚀 调度模式: Agent Teams 多平台并行验证
🏷️ 团队名称: verify-[需求ID]

👥 验证团队成员:
  ┌───────────┬───────────────────────────┬──────────────┬──────────────────┐
  │ 平台       │ 成员名                     │ 验证维度      │ 依赖              │
  ├───────────┼───────────────────────────┼──────────────┼──────────────────┤
  │ 后端       │ @backend-build-verifier   │ B1+B2+B2.5  │ 无（全并行）       │
  │ Web 端     │ @web-build-verifier       │ B3a          │ 无（全并行）       │
  │ 小程序端   │ @miniprogram-build-verifier│ B3b          │ 无（全并行）       │
  └───────────┴───────────────────────────┴──────────────┴──────────────────┘

  ⏭️ 跳过: [未启用平台] — 原因: platforms.{platform}.enabled = false

🔄 执行策略:
  - 所有平台验证成员同时启动，全并行执行（各平台之间无依赖）
  - 每个成员拥有独立上下文窗口，互不干扰
  - 领导使用委派模式，仅汇总不执行编译

📥 输入:
  - [各端实现报告路径列表]

📤 预期输出:
  - [各端 report.md 追加编译验证章节]

⚠️ 已知风险: [N] 项

请确认是否执行？[执行 / 取消]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
