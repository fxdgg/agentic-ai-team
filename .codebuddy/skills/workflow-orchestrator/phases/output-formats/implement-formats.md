# IMPLEMENT 阶段 Agent Teams 输出格式

> **加载时机**: 仅在 IMPLEMENT 阶段的预览/进度监控/总结确认时加载。
> **前置依赖**: 需同时加载 `output-formats/common.md`。

---

## 7. IMPLEMENT 阶段 Agent Teams 预览格式

```
** 📋 阶段预览: IMPLEMENT（Agent Teams 模式） **

📌 需求: [需求名称]
🔄 当前阶段: IMPLEMENT (9/15)
🚀 调度模式: Agent Teams 多智能体协作
🏷️ 团队名称: impl-[需求ID]

👥 团队成员:
  ┌───────────┬──────────────────┬──────────┬─────────────┐
  │ 优先级     │ 成员名            │ 领域      │ 依赖         │
  ├───────────┼──────────────────┼──────────┼─────────────┤
  │ P0        │ @common-dev      │ 公共模块   │ 无           │
  │ P1        │ @{domain-a}-dev  │ {领域A}    │ @common-dev  │
  │ P1        │ @{domain-b}-dev  │ {领域B}    │ @common-dev  │
  │ ...       │ ...              │ ...      │ ...         │
  └───────────┴──────────────────┴──────────┴─────────────┘

🔄 执行策略:
  - P0 独占执行 → P0 完成后 P1 并行执行 → 逐级解锁
  - 前端 Agent 依赖所有后端完成后执行（有接口交互时）
  - 领导使用委派模式，仅协调不编码

📥 输入:
  - [架构文档路径列表]

📤 预期输出:
  - [各领域实现报告路径]

⚠️ 已知风险: [N] 项

请确认是否执行？[执行 / 取消]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 8. IMPLEMENT 阶段 Agent Teams 进度监控格式

```
** 🔄 IMPLEMENT 进度: Agent Teams **

🏷️ 团队: impl-[需求ID]
⏱️ 已运行: [时长]

📊 成员状态:
  ✅ @common-dev       — 完成（P0）— 耗时 5m — 新增 3 文件，修改 2 文件
  🔄 @{domain-a}-dev  — 执行中（P1）— 已运行 3m
  🔄 @{domain-b}-dev  — 执行中（P1）— 已运行 2m
  ⏳ @{domain-c}-dev  — 等待中（P2）— 依赖 P1 完成

📈 总体进度: [1/N] 领域完成（N 由 domain-registry.json 决定）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 9. IMPLEMENT 阶段 Agent Teams 总结格式

```

🏷️ 团队: impl-[需求ID]
⏱️ 总耗时: [时长]
🚀 调度模式: Agent Teams（[N] 个成员并行协作）

📊 各领域完成情况:
  ┌────────────┬──────────┬──────────┬──────────────────────────┐
  │ 成员        │ 耗时     │ 状态      │ 摘要                      │
  ├────────────┼──────────┼──────────┼──────────────────────────┤
  │ @common-dev│ 5m       │ ✅ 完成  │ 新增 3 文件，修改 2 文件   │
  │ @user-dev  │ 8m       │ ✅ 完成  │ 新增 5 文件，修改 1 文件   │
  │ ...        │ ...      │ ...      │ ...                       │
  └────────────┴──────────┴──────────┴──────────────────────────┘

📄 产出物:
  - [各领域实现报告路径及简述]

🔑 关键决策:
  - [本阶段的关键决策点]

⚠️ 新增风险: [N] 项（来自各成员汇报）
📊 总体风险: [N] 项

下一阶段: BUILD_VERIFY
请选择: [确认进入下一阶段 / 回退到上一阶段]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
