# 🎨 B 端 UI 视觉规范 (v1.0)

> **适用角色**: 前端架构师 (`frontend-architect`) + Web 端开发 (`web-developer`)
> **定位**: 本文件是 B 端管理后台所有视觉决策的**唯一真相源**。当开发规范中的通用原则与本文件的具体数值冲突时，以本文件为准。
> **适用范围**: 使用 Ant Design + Tailwind CSS 技术栈的 B 端管理后台。其他技术栈需根据实际框架调整组件 API，但视觉规格数值保持一致。

## 1. Design Token 映射表

### 1.1 色彩系统

项目主色应在全局 ConfigProvider（如 Ant Design 的 `ConfigProvider`）中统一配置。以下为完整色彩映射：

| Token 名称 | Tailwind Class | 用途 |
|------------|---------------|------|
| **主色** | `text-primary-600` / `bg-primary-600` | 主按钮、链接、激活态 |
| **主色悬浮** | `bg-primary-700` | 主按钮 hover |
| **主色浅底** | `bg-primary-50` | 选中行背景、Tag 浅底、通知条 |
| **成功色** | `text-green-600` / `bg-green-50` | 通过/成功状态 |
| **警告色** | `text-amber-600` / `bg-amber-50` | 待审核/警告状态 |
| **危险色** | `text-red-600` / `bg-red-50` | 拒绝/删除/错误 |
| **次要文字** | `text-gray-500` | 辅助说明、placeholder |
| **正文文字** | `text-gray-700` | 表格单元格、表单值 |
| **标题文字** | `text-gray-900` | 页面标题、卡片标题、表头 |
| **边框色** | `border-gray-200` | 卡片边框、分割线 |
| **页面背景** | `bg-gray-50` | 内容区整体背景 |
| **卡片背景** | `bg-white` | 卡片、表格容器 |

**禁令**:
- ❌ 禁止使用内联 `style={{ color: '#xxx' }}`，必须使用上表中的 Tailwind class
- ❌ 禁止使用 Tailwind 中未在上表列出的灰度色（如 `gray-350`），保持色阶一致

### 1.2 间距梯度

基于 4px 网格系统，仅使用以下间距值：

| 级别 | 值 | Tailwind | 典型用途 |
|------|-----|---------|---------|
| xs | 4px | `p-1` / `gap-1` | 图标与文字间距、Tag 内边距 |
| sm | 8px | `p-2` / `gap-2` | 按钮间距、表单项内元素间距 |
| md | 12px | `p-3` / `gap-3` | 卡片内小节间距 |
| lg | 16px | `p-4` / `gap-4` | 卡片间间距、搜索栏与表格间距 |
| xl | 24px | `p-6` / `gap-6` | 页面内容区 padding、大区块间距 |
| 2xl | 32px | `p-8` / `gap-8` | 页面顶部与第一个卡片间距（罕用） |

**禁令**:
- ❌ 禁止使用 `p-5`（20px）、`p-7`（28px）等非标准间距
- ❌ 禁止使用 `margin` 内联样式，统一用 Tailwind 的 `m-*` / `space-*` / `gap-*`

### 1.3 圆角

| 场景 | 值 | Tailwind |
|------|-----|---------|
| 按钮/输入框 | 8px | `rounded-lg`（建议由 ConfigProvider `borderRadius: 8` 全局设置） |
| 卡片/容器 | 8px | `rounded-lg` |
| Tag/Badge | 4px | `rounded` |
| 头像/圆形图标 | 50% | `rounded-full` |

### 1.4 阴影

| 级别 | Tailwind | 用途 |
|------|---------|------|
| 无阴影 | — | 表格行、内嵌面板 |
| 卡片阴影 | `shadow-sm` | 所有 Card 容器 |
| 下拉阴影 | `shadow-md` | Dropdown、Popover |
| 弹窗阴影 | `shadow-xl` | Modal、Drawer |

### 1.5 字体层级

| 层级 | 大小 | 行高 | 字重 | Tailwind | 用途 |
|------|------|------|------|---------|------|
| 页面标题 | 20px | 28px | 600 | `text-xl font-semibold` | 页面顶部标题 |
| 卡片标题 | 16px | 24px | 600 | `text-base font-semibold` | Card header |
| 正文 | 14px | 22px | 400 | `text-sm`（默认） | 表格内容、表单值 |
| 辅助文字 | 12px | 20px | 400 | `text-xs text-gray-500` | 说明文字、时间戳 |

## 2. 页面布局规范

### 2.1 整体框架

```
┌──────────────────────────────────────────────────────┐
│  TopMenu (高度 56px, bg-white, shadow-sm)             │
├────────┬─────────────────────────────────────────────┤
│        │  面包屑 (高度 48px, padding 0 24px)          │
│ Side   ├─────────────────────────────────────────────┤
│ Menu   │                                             │
│        │  内容区 (padding 24px, bg-gray-50)           │
│ 宽度   │                                             │
│ 220px  │  ┌─ Card (bg-white, shadow-sm, rounded-lg) │
│        │  │  padding: 24px                           │
│ 折叠后 │  │  ...                                     │
│ 64px   │  └─────────────────────────────────────────│
│        │                                             │
└────────┴─────────────────────────────────────────────┘
```

| 区域 | 属性 | 值 |
|------|------|-----|
| 顶部导航 | 高度 | 56px |
| 侧边栏 | 展开宽度 | 220px |
| 侧边栏 | 折叠宽度 | 64px |
| 面包屑 | 高度 | 48px |
| 内容区 | padding | 24px（`p-6`） |
| 内容区 | 背景 | `bg-gray-50` |
| 卡片 | padding | 24px（`p-6`） |
| 卡片间距 | margin-bottom | 16px（`mb-4`） |

### 2.2 列表页标准布局

```
┌─ Card: 搜索区 ──────────────────────────────────────┐
│  Form (layout="inline" 或 Grid 布局)                 │
│  每行 3~4 个筛选条件，标签右对齐，宽度统一 120px       │
│  操作按钮右对齐：[重置] [查询(primary)]               │
└─────────────────────────────────────────────────────┘
        ↕ 间距 16px (mb-4)
┌─ Card: 数据区 ──────────────────────────────────────┐
│  ┌─ 工具栏 ──────────────────────────────────────┐  │
│  │  左：批量操作 / 标题       右：[新增(primary)]  │  │
│  └───────────────────────────────────────────────┘  │
│        ↕ 间距 16px (mb-4)                           │
│  ┌─ Table ───────────────────────────────────────┐  │
│  │  表头: bg-gray-50, font-semibold, text-gray-700│  │
│  │  行高: 54px                                    │  │
│  │  交替行: 偶数行 bg-gray-50/50                   │  │
│  │  悬浮行: hover:bg-primary-50/30                 │  │
│  │  操作列: 链接按钮，间距 16px，danger 色用于删除  │  │
│  └───────────────────────────────────────────────┘  │
│  ┌─ 分页 ────────────────────────────────────────┐  │
│  │  右对齐，showSizeChanger + showTotal           │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
```

### 2.3 表单页标准布局

```
┌─ 页面标题 ──────────────────────────────────────────┐
│  h1: text-xl font-semibold text-gray-900             │
└─────────────────────────────────────────────────────┘
┌─ 锚点导航（多 Panel 时）────────────────────────────┐
│  sticky 吸顶，border-b-[3px] 激活态，outline-none    │
│  gap-8，text-sm font-medium                          │
└─────────────────────────────────────────────────────┘
┌─ Card: 表单区（不使用 Card title prop）──────────────┐
│  Form (layout="horizontal", labelCol={4})            │
│                                                      │
│  h2: text-base font-semibold text-gray-900           │
│  <Divider className="mt-0 mb-6" />                   │
│  │  字段 1: [Input]（标签左对齐，输入框铺满右侧）     │
│  │  字段 2: [Select]                                 │
│  │  ...                                              │
│                                                      │
│  ⚠️ 不使用 Card 的 title prop，改用卡片内部           │
│     h2 + Divider 实现分组标题（更紧凑）               │
└─────────────────────────────────────────────────────┘
        ↕ 间距 16px (space-y-4)
┌─ Card: 下一个 Panel ────────────────────────────────┐
│  同上结构                                            │
└─────────────────────────────────────────────────────┘
┌─ 底部操作栏 (sticky bottom, bg-white)  ──────────────┐
│  居中对齐：[提交发布(primary)] [保存草稿] [取消]      │
│  高度 64px, shadow-[0_-1px_4px], Button size="large" │
└─────────────────────────────────────────────────────┘
```

| 表单属性 | 值 |
|---------|-----|
| 推荐 layout | `horizontal`（标签在左、输入在右，信息密度更高） |
| labelCol / wrapperCol | `labelCol={{ span: 4 }} wrapperCol={{ span: 18 }}`（可根据页面微调） |
| 标签对齐 | `labelAlign="right"` |
| 字段纵向间距 | 24px（Ant Design Form 默认即可） |
| 分组标题 | 卡片内部 `<h2>` + `<Divider />`，**不使用 Card 的 title prop**（更紧凑） |
| 必填星号 | Ant Design 默认在 label 前（保持默认即可） |
| 底部操作栏 | `position: sticky; bottom: 0`，白底 + 轻阴影，按钮居中排列，`size="large"` |

### 2.4 详情页标准布局

```
┌─ Card: 基本信息 ────────────────────────────────────┐
│  Descriptions (column={2} 或 {3})                    │
│  标签色: text-gray-500，值色: text-gray-900           │
│  bordered 或 无边框均可，但全项目统一                   │
└─────────────────────────────────────────────────────┘
        ↕ 间距 16px
┌─ Card: 关联数据 ────────────────────────────────────┐
│  Table / List / Timeline ...                         │
└─────────────────────────────────────────────────────┘
```

## 3. 组件视觉标准

### 3.1 表格 (Table)

| 属性 | 值 | 说明 |
|------|-----|------|
| 行高 | 54px | `size="middle"`（Ant Design 默认） |
| 表头背景 | `bg-gray-50` | 通过 `className` 或 CSS 统一设置 |
| 表头字体 | `font-semibold text-gray-700` | — |
| 交替行 | 偶数行 `bg-gray-50/50` | 提升长表格可读性 |
| 悬浮行 | `hover:bg-primary-50/30` | 鼠标经过高亮 |
| 操作列 | 链接型按钮，`type="link"` `size="small"` | 多个操作用 `<Space split={<Divider type="vertical" />}>` 分隔 |
| 删除按钮 | `danger` 属性 | 红色链接 |
| 空状态 | `<Empty description="暂无数据" />` | 禁止纯文字空状态 |
| 横向滚动 | `scroll={{ x: 'max-content' }}` | 所有表格强制设置 |
| 分页 | `showSizeChanger showTotal={(t) => \`共 ${t} 条\`}` | 右对齐 |

### 3.2 按钮 (Button)

| 场景 | 类型 | 示例 |
|------|------|------|
| 主操作（新增/保存/提交） | `type="primary"` | 一个区域**最多 1 个** primary |
| 次操作（取消/重置/导出） | `type="default"` | — |
| 危险操作（删除/下架） | `danger` | 需二次确认（Popconfirm） |
| 行内操作（查看/编辑） | `type="link" size="small"` | 表格操作列 |
| 图标按钮 | `type="text" icon={<XxxOutlined />}` | 工具栏、紧凑操作 |
| 按钮间距 | 8px | `<Space size={8}>` 或 `gap-2` |

### 3.3 弹窗 (Modal / Drawer)

| 属性 | 值 |
|------|-----|
| 小型确认 | Modal 宽度 `420px` |
| 标准表单 | Modal 宽度 `640px` |
| 复杂表单/预览 | Modal 宽度 `800px` 或 Drawer 宽度 `720px` |
| 标题 | `text-base font-semibold` |
| 底部按钮 | 右对齐，[取消] [确定(primary)] |
| 关闭方式 | 支持右上角 X + ESC 键 + 点击蒙层（危险操作除外） |
| 蒙层 | Ant Design 默认（保持不变） |

### 3.4 Tag 状态色映射

| 业务状态 | Ant Design Tag color | 示例 |
|---------|---------------------|------|
| 草稿/未开始 | `default` | 灰色 |
| 进行中/待处理 | `processing` | 蓝色 |
| 待审核/警告 | `warning` | 橙色 |
| 已通过/成功 | `success` | 绿色 |
| 已拒绝/失败 | `error` | 红色 |

> **强制**：同一状态在全项目中必须使用相同的 Tag 颜色，不允许同一状态在不同页面使用不同颜色。

### 3.5 搜索表单

| 属性 | 值 |
|------|-----|
| 布局 | 一行 3~4 个条件（响应式：xl:4, lg:3, md:2） |
| 操作按钮 | 右对齐，[重置(default)] [查询(primary)] |
| 展开/收起 | 超过 1 行时显示「展开」链接 |
| 间距 | 字段间 `gap-4`（16px），行间 `gap-4` |

### 3.6 面包屑

| 属性 | 值 |
|------|-----|
| 字体 | `text-sm text-gray-500` |
| 当前页 | `text-gray-900`（不可点击） |
| 分隔符 | `/`（Ant Design 默认） |
| 位置 | 内容区顶部，padding 与内容区对齐 |

### 3.7 消息反馈

| 场景 | 组件 | 示例 |
|------|------|------|
| 操作成功 | `message.success()` | "保存成功"、"删除成功" |
| 操作失败 | `message.error()` | "保存失败，请重试" |
| 危险确认 | `Popconfirm` / `Modal.confirm` | "确定要删除吗？删除后不可恢复" |
| 表单校验 | Ant Design Form 内置 | 红色边框 + 下方提示文字 |
| 加载状态 | `Spin` 包裹或 `Button loading` | 提交按钮 loading + 禁用 |

## 4. 响应式断点

| 断点 | Tailwind | 内容区行为 |
|------|---------|-----------|
| ≥1440px | `2xl:` | 搜索栏 4 列 |
| ≥1280px | `xl:` | 搜索栏 3~4 列 |
| ≥1024px | `lg:` | 搜索栏 3 列 |
| ≥768px | `md:` | 搜索栏 2 列，侧边栏自动折叠 |

> B 端后台最小支持宽度 **1280px**。小于此宽度不做适配。

## 5. 禁令清单（视觉相关）

1. ❌ **禁止**使用内联 `style={{ ... }}` 处理间距、颜色、字体（必须用 Tailwind class）
2. ❌ **禁止**在不同页面对同一状态使用不同颜色的 Tag
3. ❌ **禁止**使用 Ant Design 默认 `<Empty />` 以外的空状态展示方式（如纯文字 "暂无数据"）
4. ❌ **禁止**省略表格的交替行背景
5. ❌ **禁止**一个视觉区域内出现超过 1 个 `type="primary"` 按钮
6. ❌ **禁止**危险操作（删除等）不带二次确认
7. ❌ **禁止**使用非标准间距值（参见 §1.2 间距梯度）
8. ❌ **禁止**表单页没有底部固定操作栏
9. ❌ **禁止**卡片不带 `shadow-sm` 和 `rounded-lg`

## 6. 前端架构师专用：视觉规格输出要求

> 本节仅供 `frontend-architect` Agent 参照，指导架构文档中组件设计章节的输出格式。

### 6.1 页面布局骨架描述（必须）

每个新增页面在架构文档中必须包含文字版布局骨架：

```markdown
### 页面布局骨架

**用户列表页** (`/user/list`):
- 布局类型: 列表页标准布局（参照 ui-visual-spec.md §2.2）
- 搜索区: 4 个筛选条件（用户名/角色/状态/创建时间）
- 数据区工具栏: 左侧「批量操作」下拉 + 右侧「新增用户」primary 按钮
- 表格列: 6 列（用户名/角色/状态/创建时间/最后登录/操作）
- 操作列: 查看 | 编辑 | 删除(danger)
```

### 6.2 组件视觉规格（新增组件时必须）

每个新增自定义组件必须标注引用的 Design Token：

```markdown
### AnchorNav 组件视觉规格

- 容器: bg-white, rounded-lg, shadow-sm, p-4
- 锚点项: text-sm text-gray-500, 选中态 text-primary-600 font-semibold
- 锚点项间距: gap-3 (12px)
- 分隔线: border-b border-gray-200
- 参考组件: Ant Design Anchor（定制样式）
```

## 7. Web 端开发专用：UI 质量自检清单

> 本节仅供 Web 端开发 Agent 参照，每次完成页面实现后必须逐项检查。

```markdown
### UI 质量自检（强制）
- [ ] 页面内容区 padding 为 24px (`p-6`)
- [ ] 所有卡片使用 `shadow-sm rounded-lg bg-white p-6`
- [ ] 卡片间距为 16px (`mb-4`)
- [ ] 表格设置了交替行背景（偶数行 `bg-gray-50/50`）
- [ ] 表格悬浮行高亮（`hover:bg-primary-50/30`）
- [ ] 表格操作列使用链接型按钮，删除用 `danger`
- [ ] 空状态使用 `<Empty />` 组件
- [ ] 表单页有底部固定操作栏（sticky bottom）
- [ ] 每个视觉区域最多 1 个 primary 按钮
- [ ] 危险操作带二次确认（Popconfirm / Modal.confirm）
- [ ] 状态 Tag 颜色与 §3.4 映射表一致
- [ ] 所有间距使用标准梯度值（4/8/12/16/24/32px）
- [ ] 无内联 style 处理间距/颜色/字体
```
